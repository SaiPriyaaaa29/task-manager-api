# Task Manager API

A RESTful backend for managing tasks, built with Java and Spring Boot. It supports full CRUD operations, input validation, consistent JSON error responses, and automated tests.

## Tech Stack

- Java 17
- Spring Boot 4 (Spring Web, Spring Data JPA, Bean Validation)
- H2 in-memory database
- Maven
- JUnit 5 and Mockito for testing

## Features

- Create, read, update and delete tasks
- Filter tasks by status (`TODO`, `IN_PROGRESS`, `DONE`)
- Input validation with clear error messages
- Global exception handling with consistent JSON error responses
- Layered architecture: controller, service, repository
- Unit tests for the service layer and the web layer

## API Endpoints

| Method | Endpoint                    | Description                     | Success |
|--------|-----------------------------|---------------------------------|---------|
| GET    | `/api/tasks`                | List all tasks                  | 200     |
| GET    | `/api/tasks?status=DONE`    | List tasks filtered by status   | 200     |
| GET    | `/api/tasks/{id}`           | Get one task                    | 200     |
| POST   | `/api/tasks`                | Create a task                   | 201     |
| PUT    | `/api/tasks/{id}`           | Update a task                   | 200     |
| DELETE | `/api/tasks/{id}`           | Delete a task                   | 204     |

### Task fields

| Field         | Type   | Rules                                   |
|---------------|--------|-----------------------------------------|
| `id`          | Long   | Generated by the database               |
| `title`       | String | Required, max 100 characters            |
| `description` | String | Optional, max 500 characters            |
| `status`      | Enum   | `TODO` (default), `IN_PROGRESS`, `DONE` |
| `createdAt`   | Date   | Set automatically                       |

### Example requests

Create a task:

```bash
curl -X POST http://localhost:8080/api/tasks \
  -H "Content-Type: application/json" \
  -d '{"title":"Learn Spring Boot","description":"Build a REST API"}'
```

Example error response (empty title, HTTP 400):

```json
{
  "timestamp": "2026-09-25T10:15:30",
  "status": 400,
  "error": "Validation Failed",
  "errors": { "title": "Title is required" }
}
```

Example error response (unknown id, HTTP 404):

```json
{
  "timestamp": "2026-09-25T10:16:02",
  "status": 404,
  "error": "Not Found",
  "message": "Task not found with id: 999"
}
```

## Running the Project

Prerequisite: JDK 17 or higher.

```bash
git clone https://github.com/SaiPriyaaaa29/task-manager-api.git
cd task-manager-api
./mvnw spring-boot:run
```

On Windows PowerShell, use `.\mvnw.cmd spring-boot:run`.

The API starts on `http://localhost:8080`. Data is stored in memory, so it resets every time the app restarts.

## Running the Tests

```bash
./mvnw test
```

The suite contains 14 tests:

- **Service tests (8):** Mockito-based unit tests covering create, read, update, delete, filtering, and the not-found cases.
- **Controller tests (6):** `MockMvc` tests checking status codes, JSON responses, validation errors (400) and not-found errors (404).
